## How to install Yarn & NPM 
Yarn is an open-source package manager for JavaScript that helps install, update, and manage packages. We use it in our project to manage dependencies and run the project. To install, you have to have NPM installed, a free registry of JavaScript packages and tools for managing them. It's the default package manager for Node.js, an open-source JavaScript environment for building web applications. These are the following links to download both tools:

### NPM:
https://docs.npmjs.com/downloading-and-installing-node-js-and-npm

### Yarn:
https://classic.yarnpkg.com/lang/en/docs/install/

## How to install and launch the application
<b>N.B</b>: the app is also accessible through this URL we have it hosted on: https://chatbot-brown-team.netlify.app/ <br>
Additionally, to run the application once yarn is installed, if this is the first time you are trying to run the app, you first need to run the yarn command to download the project dependencies onto your computer: 

### yarn install 
This command is used to download project dependencies these include:

```json
"dependencies": {
   "@lottiefiles/react-lottie-player": "^3.6.0", (Animation Library)
   "@radix-ui/react-label": "^2.1.2",  (UI Library)
   "@radix-ui/react-select": "^2.1.6",  (UI Library)
   "@radix-ui/react-slot": "^1.1.2", (UI Library)

 }
```

Then, after the install command, which only has to be run on the first install, you can now run the project using the run command: 

### yarn run dev 
This command starts up a web server and will provide the port on localhost the app is running on, which you access in your browser i.e.:
